# MVP 운영 가이드

## 포함 기능

- 회원가입과 Google/GitHub OAuth 로그인
- Easy, Medium, Hard 난이도의 오프라인 교육용 CTF 3문제
- 게시글과 댓글 작성·수정·삭제
- 관리자 계정 자동 생성, 사용자 정지·재활성·익명 비활성화
- 제출 기록, 로그인/가입 이벤트, 관리자 감사 로그, 부정행위 검토 신호
- 프로필 사진·상태 메시지, 친구 요청·수락, 친구 간 개인 메시지

## 관리자 계정

서버는 시작할 때 `.env`의 `ADMIN_USERNAME`, `ADMIN_PASSWORD`로 관리자 계정을 한 번 생성합니다.
이미 생성된 계정의 비밀번호는 환경 변수 변경만으로 바뀌지 않습니다. 운영 환경에서는 충분히 긴
고유 비밀번호를 사용하고, 비밀번호를 저장소에 커밋하지 마세요.

관리자로 로그인하면 상단의 **Admin** 메뉴에서 사용자를 편집·정지·재활성화하고, 계정 비활성화,
최근 제출, 의심 신호와 감사 로그를 확인할 수 있습니다. 게시글/댓글은 Community 화면에서 관리자도
수정·삭제할 수 있습니다.

로그인/회원가입 이벤트와 관리자 행동은 Admin 화면에서 확인합니다. 기록의 행동 유형과 시각은
감사성을 위해 바꾸지 않으며, 관리자는 사유를 남겨 세부 내용을 **Redact**하거나 활성 화면에서
**Hide**할 수 있습니다. 비밀번호, JWT, OAuth 토큰, 개인 메시지 내용은 보안 이벤트에 기록하지
않습니다.

## 프로필과 개인 메시지

모든 로그인 사용자는 My Page에서 표시 이름, 160자 이내 상태 메시지, PNG/JPEG 프로필 사진(2MB
이하)을 관리할 수 있습니다. 친구 요청은 상대방의 username으로 보내며, 상대방이 수락한 뒤에만
개인 메시지를 주고받을 수 있습니다. 게시글과 마찬가지로 메시지는 HTML이 아닌 일반 텍스트로
저장됩니다.

## MVP 문제

서버 시작 시 다음 문제와 아티팩트가 자동 생성됩니다.

| 난이도 | 문제 | 유형 | 점수 |
|---|---|---|---:|
| Easy | Signal in Plain Sight | Crypto | 100 |
| Medium | Proxy Afterimage | Forensics | 250 |
| Hard | Orbit Gatekeeper | Reversing | 500 |

FLAG는 처음 실행 시 `challenges/.mvp-flags.properties`에 무작위로 생성되며 Git에서 제외됩니다.
아티팩트와 이 파일을 함께 백업해야 운영 중 FLAG가 바뀌지 않습니다.

## 부정행위 대응 원칙

이 MVP는 AI 사용 여부를 판정하거나 자동 처벌하지 않습니다. 대신 로그인한 사용자의 문제 열람·파일
다운로드·포커스 전환 및 제출 시점으로 다음 **검토 신호**를 만듭니다.

- 문제 활동 기록 없이 정답 제출
- 난이도별 최소 검토 시간보다 매우 빠른 정답 제출
- 기존 FLAG/Community 요청 속도 제한

신호는 관리자 화면에서 사람의 검토를 위한 보조 정보로만 사용합니다. 화면·키보드·클립보드 내용이나
대화 내용은 수집하지 않습니다.
